Monospace text (issue IDs, `bd` commands) uses the visitor's system monospace font; nothing is bundled for it.

The agent logos are shown in one ink (paper on the ink avatar tile) instead of their brand colours, to keep the board hue-free. They identify which agent holds an issue and do not imply endorsement; if you redistribute the project, check each owner's brand guidelines for your use.

The OFL allows bundling, modifying and redistributing the font with the project, including commercially. It does not allow selling the font on its own. A modified font must not be called "Onest" (Reserved Font Name rules in OFL.txt).
